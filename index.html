GCPの画面でやること

最初に一度だけ。5分ほど
リンクはすべてクリックできます。開くとGoogle Cloudの該当画面に直接飛びます。 プロジェクトを複数お持ちの場合は、画面上部で目的のプロジェクトが選ばれているか 必ず確認してください。

プロジェクトを選ぶ

画面上部の青いバーに、いまどのプロジェクトを開いているかが出ています。ここが目的のプロジェクトになっているか確認してください。違っていたら名前の部分をクリックして選び直します。

https://console.cloud.google.com/projectselector2/home/dashboard

プロジェクトIDを控えておいてください。あとで使います。

Vertex AI API を有効にする

上のリンクを開くと「Vertex AI API」のページが出ます。青い「有効にする」ボタンを押してください。すでに有効な場合は「管理」と表示されているので、そのままで結構です。

https://console.cloud.google.com/apis/library/aiplatform.googleapis.com

これが図面を読ませるための本体です。Apps Script からこのAPIを呼びます。

課金アカウントを紐づける

左メニューの「お支払い」を開きます。このプロジェクトに課金アカウントが紐づいていないと、APIを呼んだ時点でエラーになります。「請求先アカウントをリンク」から設定してください。

https://console.cloud.google.com/billing

図面1枚あたり1〜3円程度です。無料枠の範囲で試せます。

操作する人に権限を付ける

左メニューの「IAMと管理」→「IAM」を開きます。「アクセスを許可」を押し、担当者のGoogleアカウントを入力して、ロールに「Vertex AI ユーザー」を選んで保存します。

https://console.cloud.google.com/iam-admin/iam

オーナー権限は不要です。読み取りと実行だけで動きます。

動いているか確かめる

https://console.cloud.google.com/vertex-ai

返らない場合は、2〜4のどれかが未完了です。

エージェントはどこにあるのか

いまの形 ― 作る必要はありません

エージェントの実体は手元のプログラムです。 GCPの画面に「エージェント」という項目が増えるわけではありません。

GCP側は、そのプログラムからGeminiを呼ぶことを許可しているだけです。 画面で作るものは何もなく、上の1〜4を済ませれば動きます。

外部のシステムから呼びたい場合

「別のシステムからAPIで呼びたい」という場合は、 エージェントをGoogle Cloudに置きに行く作業が必要になります。

Vertex AI は Gemini Enterprise Agent Platform に統合され、 ADKで作ったエージェントは agents-cli deploy で配置できます。 配置するとURLが発行され、そこに対して呼び出せるようになります。

この配置はまだ行っていません。必要になった時点で進めます。

順番を決めているのはコードです

AIに「次に何をするか」を決めさせていません。決めさせると、 順番が変わったり工程を飛ばしたりして、 同じ図面でも結果が変わります。

コードが1→2→3の順に呼び、各工程の中身だけをAIに任せています。

鍵の管理が要りません

APIキーは使いません。ScriptApp.getOAuthToken() で、 実行している人のGoogleアカウントの権限で呼びます。

誰が使えるかはGCP側のIAMで決まります。 キーを配ったり、漏れを心配したりする必要がありません。

1回あたりを短くする

Apps Script の実行は1回6分までです。 まとめて呼ぶと、項目が増えたときにここに当たります。

工程ごとに分けて呼べば、1回あたりが短くなり余裕が出ます。 画面にも進み具合が出せます。

費用は呼んだ分だけ

常時動くサーバーがないため、待機中の費用はかかりません。 図面を確認したときだけ、2回分の呼び出しが発生します。

1図面あたりの実費はまだ実測していません。 運用の見込み枚数が決まった時点で測ります。

doGet が HTML を返し、画面から google.script.run でサーバー側の関数を呼びます。 画面用のサーバーは立てません。

図面の一覧はドライブから、項目数はチェック項目表から その場で読み込むため、増えても画面の直しは要りません。

用途は図面チェックと品番リピート確認の2つです。 図面は同じものを使うので、画面は1つにしてタブで分けています。

チャット画面にはしません

担当者の操作は「図面を選ぶ」「押す」の2つだけです。 指示文はこちら側で固定しています。

自由に書ける入力欄にすると、聞き方で結果が変わり、 担当者ごとに判定がばらつきます。 同じ図面なら誰が動かしても同じ結果になる必要があります。

/**
 * 図面チェック（作図基準）― 1ファイル版
 *
 * Apps Script のエディタに、この内容をまるごと貼り付けて使う。
 *
 * 画面は AppSheet に持たせる。この中に HTML は含まない。
 *
 * 手順:
 *   1. https://script.new を開く
 *   2. 既定の myFunction ごと消して、この内容を貼り付けて保存
 *   3. ⚙プロジェクトの設定 →「appsscript.json をエディタで表示する」にチェック
 *      → appsscript.json を差し替える（権限の指定。これが無いと403になる）
 *   4. setupProperties() を実行する
 *   5. setupSettingsSheet() → setupAppSheetSheets() を実行する
 *   6. installPendingTrigger() を実行する
 *   7. AppSheet で画面を作る
 *
 * 3を飛ばすと Vertex AI の呼び出しが HTTP 403 で失敗し、
 * 6でトリガーを作るところでも権限エラーになる。
 * コードから権限は推測されないため、必ず明示する。
 *
 * 動作確認だけなら、runCheck() の図面IDを書き換えて実行すれば足りる。
 * AppSheet を作る前に、読めているかをここで確かめられる。
 *
 * 保守は分割版（Config / Settings / VertexAI / Items / Check /
 * Repeat / Drawings / AppSheet）で行う。
 * ウェブ画面版は src/webui/Ui.gs に残してある。束ねる対象からは外した。
 */

// ====================================================================
// Config.gs
// ====================================================================

/**
 * 設定値。スクリプトプロパティに入れておく。
 *
 * コードに直接書かないのは、先方環境へ移すときに
 * ここだけ差し替えれば済むようにするため。
 */
const CONFIG_KEYS = {
  GCP_PROJECT_ID: 'GCP_PROJECT_ID',     // 例 sapient-stacker-504215-u4
  VERTEX_LOCATION: 'VERTEX_LOCATION',   // 例 asia-northeast1
  VERTEX_MODEL: 'VERTEX_MODEL',         // 例 gemini-3.5-flash
  ITEMS_SHEET_ID: 'ITEMS_SHEET_ID',     // チェック項目表のスプレッドシートID
  ITEMS_SHEET_NAME: 'ITEMS_SHEET_NAME', // 既定は「チェック項目」
  RESULT_SHEET_NAME: 'RESULT_SHEET_NAME', // 既定は「チェック結果」
  DRAWING_FOLDER_ID: 'DRAWING_FOLDER_ID' // 図面PDFを置くフォルダ
};

function getConfig() {
  const p = PropertiesService.getScriptProperties().getProperties();
  const cfg = {
    projectId: p[CONFIG_KEYS.GCP_PROJECT_ID],
    location: p[CONFIG_KEYS.VERTEX_LOCATION] || 'asia-northeast1',
    // モデルは設定シートでも変えられる。まずスクリプトプロパティを見る。
    model: p[CONFIG_KEYS.VERTEX_MODEL] || 'gemini-3.5-flash',
    itemsSheetId: p[CONFIG_KEYS.ITEMS_SHEET_ID],
    itemsSheetName: p[CONFIG_KEYS.ITEMS_SHEET_NAME] || 'チェック項目',
    resultSheetName: p[CONFIG_KEYS.RESULT_SHEET_NAME] || 'チェック結果',
    drawingFolderId: p[CONFIG_KEYS.DRAWING_FOLDER_ID]
  };
  if (!cfg.projectId) {
    throw new Error(
      'GCP_PROJECT_ID が未設定です。' +
      '「プロジェクトの設定」→「スクリプト プロパティ」で設定してください。');
  }
  return cfg;
}

/**
 * 初回の設定を、この関数を実行して行う。
 * 値を自社のものに書き換えてから実行すること。
 *
 * 図面フォルダを切り替えたいときは、DRAWING_FOLDER_ID の1行だけを
 * 差し替えて、もう一度この関数を実行する。
 * 貼るファイルを分けると、どちらを貼ったか分からなくなる。
 *
 *   zumen（既定） 1s2Er6n7Iq2Wam9igHMwKd0F2-2z63zu9
 *   先方フォルダ  1_-VNjp7jFvqBIdy4ukvt6PWegnHL5v6T
 *
 * スプレッドシートを切り替えるときは ITEMS_SHEET_ID を差し替える。
 *   図面検証用    1fybB0V-aYlYNCJrRfJokBxtNCs3t2N9R-k3qVWO8uN0（既定）
 */
function setupProperties() {
  PropertiesService.getScriptProperties().setProperties({
    GCP_PROJECT_ID: 'sapient-stacker-504215-u4',

/**
 * 指示文（プロンプト）を設定シートから読む。
 *
 * 指示文をコードに書くと、直すたびに開発が要る。
 * 読み方を変えたい、判定を厳しくしたい——運用しながら何度も出てくる。
 * チェック項目を表に出したのと同じ理由で、指示文も表に出す。
 *
 * シートが無い場合はコードの既定値を使う。
 * 設定を用意しないと動かない、という状態にはしない。
 *
 * 使い方:
 *   1. チェック項目表と同じスプレッドシートに「設定」シートを作る
 *   2. setupSettingsSheet() を実行すると、雛形と既定値が入る
 *   3. B列を書き換えれば、次の実行から反映される
 */

const SETTINGS_SHEET = '設定';

/** 設定シートの行。A列がキー、B列が値。 */
const SETTING_KEYS = {
  extract: '読み取りの指示',
  judge: '判定の指示',
  codes: '品番の指示',
  model: 'モデル'
};


/**
 * 設定シートを読む。1回の実行で何度も呼ぶため、結果を持ち回す。
 *
 * シートが無い、行が無い、値が空——どの場合も既定値に戻す。
 * 設定の不備で止めない。
 */
let SETTINGS_CACHE_ = null;

function getSettings() {
  if (SETTINGS_CACHE_) return SETTINGS_CACHE_;

  const out = {};
  try {
    const cfg = getConfig();
    const sh = SpreadsheetApp.openById(cfg.itemsSheetId)
      .getSheetByName(SETTINGS_SHEET);
    if (sh) {
      const values = sh.getDataRange().getValues();
      for (let i = 0; i < values.length; i++) {
        const key = String(values[i][0] || '').trim();
        const val = String(values[i][1] || '').trim();
        if (key && val) out[key] = val;
      }
    }
  } catch (e) {
    // 設定が読めなくても本体は動かす。理由だけログに残す。
    Logger.log('設定シートを読めませんでした（既定値で動きます）: %s', e.message);
  }
  SETTINGS_CACHE_ = out;
  return out;
}


/**
 * 設定シートの値を取る。無ければ既定値。
 * 既定値はコード側に持つので、シートを消しても動く。
 */
function setting_(key, fallback) {
  const v = getSettings()[key];
  return (v && v.length) ? v : fallback;
}


/**
 * 設定シートの雛形を作る。1回だけ実行する。
 * すでにある場合は、空欄の行だけを埋める。既存の文言は上書きしない。
 */
function setupSettingsSheet() {
  const cfg = getConfig();
  const ss = SpreadsheetApp.openById(cfg.itemsSheetId);
  let sh = ss.getSheetByName(SETTINGS_SHEET);
  if (!sh) {
    sh = ss.insertSheet(SETTINGS_SHEET);
    sh.appendRow(['設定項目', '値', '説明']);
    sh.getRange(1, 1, 1, 3).setFontWeight('bold').setBackground('#EDF1F5');
    sh.setFrozenRows(1);
    sh.setColumnWidth(1, 160);
    sh.setColumnWidth(2, 640);
    sh.setColumnWidth(3, 300);
  }

  // ページ番号は差し込まず、{ページ} のまま雛形に入れる。
  // ここで extractPrompt_(1) と書くと「1ページ目」で固定された文章が
  // シートに入り、以後どのページを指定しても1ページ目しか読まなくなる。
  // 置き換えは実行時に行うので、雛形には目印を残しておく。
  const PAGE_MARK = '{ページ}';
  const defaults = [
    [SETTING_KEYS.extract, extractPromptDefault_(PAGE_MARK),
     '図面を読み取らせる指示。{ページ} と書くと対象ページ番号に置き換わります'],
    [SETTING_KEYS.judge, JUDGE_PROMPT_HEAD_,
     'チェック項目に照らして判定させる指示。抽出結果と項目表は自動で付きます'],
    [SETTING_KEYS.codes, codesPromptDefault_(PAGE_MARK),
     'クロス品番を抜き出させる指示。{ページ} が使えます'],
    [SETTING_KEYS.model, cfg.model, '使用するモデル名']
  ];

  const rows = sh.getDataRange().getValues();
  const seen = {};
  for (let i = 1; i < rows.length; i++) {
    seen[String(rows[i][0] || '').trim()] = i + 1;
  }

  defaults.forEach(function (d) {
    const at = seen[d[0]];
    if (!at) {
      sh.appendRow(d);
    } else if (!String(sh.getRange(at, 2).getValue() || '').trim()) {
      // 行はあるが値が空。既定値を入れる。書かれているものは触らない。
      sh.getRange(at, 2).setValue(d[1]);
      sh.getRange(at, 3).setValue(d[2]);
    }
  });

  sh.getRange(2, 1, sh.getLastRow() - 1, 3)
    .setVerticalAlignment('top').setWrap(true);
  Logger.log('「%s」シートを用意しました。B列を書き換えると次の実行から反映されます。',
             SETTINGS_SHEET);
  return ss.getUrl() + '#gid=' + sh.getSheetId();
}

/**
 * Vertex AI（Gemini）を呼ぶ。
 *
 * APIキーは使わない。実行している人のGoogleアカウントの権限で呼ぶため、
 * 鍵の管理が要らず、権限はGCP側のIAMで一元的に決められる。
 *
 * PDFはそのまま渡せる。画像への変換は不要。

/**
 * 図面PDFとプロンプトを渡して、JSONで受け取る。
 *
 * @param {Blob} pdfBlob 図面のPDF
 * @param {string} prompt 指示文
 * @param {Object} cfg getConfig() の戻り値
 * @return {Object} モデルが返したJSON
 */
function askWithPdf(pdfBlob, prompt, cfg) {
  const body = {
    contents: [{
      role: 'user',
      parts: [
        { inlineData: { mimeType: 'application/pdf',
                        data: Utilities.base64Encode(pdfBlob.getBytes()) } },
        { text: prompt }
      ]
    }],
    generationConfig: { temperature: 0.2, responseMimeType: 'application/json' }
  };
  return callVertex_(body, cfg);
}

/**
 * 文字だけを渡して、JSONで受け取る。工程2以降で使う。
 */
function askText(prompt, cfg) {
  const body = {
    contents: [{ role: 'user', parts: [{ text: prompt }] }],
    generationConfig: { temperature: 0.2, responseMimeType: 'application/json' }
  };
  return callVertex_(body, cfg);
}

function callVertex_(body, cfg) {
  const url = 'https://' + cfg.location + '-aiplatform.googleapis.com/v1/projects/' +
    cfg.projectId + '/locations/' + cfg.location +
    '/publishers/google/models/' + cfg.model + ':generateContent';

  const res = UrlFetchApp.fetch(url, {
    method: 'post',
    contentType: 'application/json',
    headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() },
    payload: JSON.stringify(body),
    muteHttpExceptions: true
  });

  const code = res.getResponseCode();
  if (code !== 200) {
    throw new Error('Vertex AI の呼び出しに失敗しました（HTTP ' + code + '）\n' +
                    res.getContentText().slice(0, 500));
  }
  const data = JSON.parse(res.getContentText());
  const text = ((((data.candidates || [])[0] || {}).content || {}).parts || [])
    .map(function (p) { return p.text || ''; }).join('');
  return parseJson_(text);
}

/**
 * モデルの出力からJSONを取り出す。前後に説明が付くことがある。
 *
 * JSONを返すよう指示していても、配列で包んで返してくることがある。
 * そのまま渡すと後段が壊れるため、配列なら中のオブジェクトを取り出す。
 */
function parseJson_(text) {
  if (!text) return null;
  const m = text.match(/[\[{][\s\S]*[\]}]/);
  if (!m) return null;
  let data;
  try {
    data = JSON.parse(m[0]);
  } catch (e) {
    return null;
  }
  if (Array.isArray(data)) {
    for (let i = 0; i < data.length; i++) {
      if (data[i] && typeof data[i] === 'object' && !Array.isArray(data[i])) {
        return data[i];
      }
    }
    return null;
  }
  return data;
}

/**
 * チェック項目を、スプレッドシートから毎回読む。
 *
 * 項目をコードに書くと、1つ増やすたびに開発と再公開が要る。
 * 表の行として持てば、担当者が行を足すだけで次の実行から効く。
 */

const ITEM_ALIASES = {
  no: ['No', 'no', '番号'],
  target: ['対象', 'target', '対象の図面'],
  item: ['チェック項目', 'item', 'チェックしたいこと'],
  basis: ['判定の根拠となる基準', '基準', 'basis', 'どうなっていたらNGか'],
  source: ['出典', 'source'],
  judge: ['判定可否', 'judge'],
  use: ['採用', 'use', '利用']
};

function pick_(row, header, key) {
  const names = ITEM_ALIASES[key];
  for (let i = 0; i < names.length; i++) {
    const idx = header.indexOf(names[i]);
    if (idx >= 0 && String(row[idx] || '').trim()) {
      return String(row[idx]).trim();
    }
  }
  return '';
}

/**
 * 項目を読む。対象を指定すると、その図面向けと全図面共通のものを返す。
 */
function loadItems(target, cfg) {
  cfg = cfg || getConfig();
  // 指定した名前のシートが無ければ、先頭のシートを使う。
  // CSVから作ったスプレッドシートはシート名がファイル名になるなど、
  // 名前が揃わないことが多いため、そこで止めない。
  const ss = SpreadsheetApp.openById(cfg.itemsSheetId);
  const sh = ss.getSheetByName(cfg.itemsSheetName) || ss.getSheets()[0];
  if (!sh) throw new Error('シートが1つもありません。');
  const values = sh.getDataRange().getValues();
  if (values.length < 2) return [];

  const header = values[0].map(function (h) { return String(h).trim(); });
  const rows = [];
  for (let i = 1; i < values.length; i++) {
    const item = pick_(values[i], header, 'item');
    if (!item) continue;

    // 「採用」欄が × の行は使わない。空欄は採用とみなす。
    const use = pick_(values[i], header, 'use');
    if (['×', 'x', 'X', '対象外', 'なし'].indexOf(use) >= 0) continue;

    rows.push({
      no: pick_(values[i], header, 'no') || String(rows.length + 1),
      target: pick_(values[i], header, 'target') || '全図面',
      item: item,
      basis: pick_(values[i], header, 'basis'),
      source: pick_(values[i], header, 'source'),
      judge: pick_(values[i], header, 'judge') || '自動'
    });
  }

  const filtered = target
    ? rows.filter(function (r) { return r.target === target || r.target === '全図面'; })
    : rows;

  // 判定方法が固まっているものを先に並べる
  const order = { '自動': 0, '半自動': 1, '要検討': 2 };
  filtered.sort(function (a, b) {
    return (order[a.judge] === undefined ? 9 : order[a.judge]) -
           (order[b.judge] === undefined ? 9 : order[b.judge]);
  });
  return filtered;
}

function itemsAsText(items) {
  return items.map(function (r) {
    return r.no + '. ' + r.item + '\n    基準: ' + (r.basis || '―');
  }).join('\n');
}

/** 表に出てくる対象の一覧。画面の選択肢に使う。 */
function listTargets() {
  const rows = loadItems(null);
  const seen = [];
  rows.forEach(function (r) {
    if (r.target !== '全図面' && seen.indexOf(r.target) < 0) seen.push(r.target);
  });
  return seen;
}

/**
 * 作図基準のチェック本体。
 *
 * 工程1 読み取る   図面の記載を、位置つきで抜き出す（Gemini）
 * 工程2 判定する   表の行を1つずつ見て判定する（Gemini）
 * 工程3 検証する   根拠が工程1の結果に実在するか（JavaScript）
 * 工程4 まとめる   確定・要確認・棄却に振り分ける（JavaScript）
 *
 * 工程3・4をAIに任せない。自分の出した根拠を自分で検証させても、
 * 実在しない文言をそのまま通してしまう。
 *
 * Apps Script の実行は6分までなので、この2回の呼び出しで収める。
 * 品番ごとにメーカーを調べる処理は件数分の呼び出しになり6分に収まらないため、
 * そちらは別立てにする（Batch.gs）。
 */

/** 読み取りの指示。設定シートに書かれていれば、そちらを使う。 */
function extractPrompt_(pageNo) {
  const custom = setting_(SETTING_KEYS.extract, '');
  if (custom) return custom.replace(/\{ページ\}/g, String(pageNo));
  return extractPromptDefault_(pageNo);
}

function extractPromptDefault_(pageNo) {
  return 'この図面の' + pageNo + 'ページ目に書かれている内容を、' +
  'そのまま構造化して抜き出してください。\n\n' +
  '厳守事項:\n' +
  '・図面に書かれていないことを補わない。推測で埋めない。\n' +
  '・読み取れなかった箇所は、読み取れなかったと明記する。\n' +
  '・各記載には図面上の位置を box_2d で付ける。\n' +
  '  box_2d は [y0, x0, y1, x1] の順で、0〜1000 に正規化した値とする。\n\n' +
  '次の JSON だけを出力してください。\n' +
  '{"drawing_title":"図面の名称","drawing_number":"図面番号。無ければ空",' +
  '"scale":"縮尺。無ければ空",' +
  '"texts":[{"text":"記載されている文字列","box_2d":[0,0,0,0]}],' +
  '"unreadable":["読み取れなかった箇所"]}';
}

/**
 * 判定の指示文の本体。抽出結果と項目表は、この前に自動で付く。
 * 設定シートに書かれていれば、そちらが優先される。
 */
const JUDGE_PROMPT_HEAD_ =
  'この抽出結果だけを根拠に、項目を1件ずつ判定してください。\n' +
  '図面を見直さず、抽出結果に無いことは「要確認」としてください。\n\n' +
  '判定は3つから選びます。\n' +
  '  適合    基準を満たす記載が抽出結果にある\n' +
  '  要確認  記載が見当たらない、または満たすか判断できない\n' +
  '  対象外  この図面には当てはまらない項目\n\n' +
  '厳守事項:\n' +
  '・根拠には、抽出結果に含まれる文字列をそのまま引用する。\n' +
  '・引用できないときは根拠を空にする。引用文を作らない。\n\n' +
  '次の JSON だけを出力してください。\n' +
  '{"results":[{"no":"項目番号","verdict":"適合|要確認|対象外",' +
  '"evidence":"抽出結果から引用した文字列","reason":"判定の理由"}]}';

function judgePrompt_(extracted, items) {
  return 'あなたは作図基準に照らして図面を確認する担当です。\n\n' +
    '# 工程1の抽出結果\n' + JSON.stringify(extracted) + '\n\n' +
    '# チェック項目\n' + itemsAsText(items) + '\n\n' +
    setting_(SETTING_KEYS.judge, JUDGE_PROMPT_HEAD_);
}

/**
 * 表記の揺れを吸収して比べる。
 *
 * 全角の英数字だけを変換していたら、＝ や ＋ が残って
 * 「設計GL＝ＢＭ＋１５０」と「設計GL=BM+150」が別物になった。
 * NFKC 正規化なら記号も含めてまとめて揃う。Python 側と同じ扱いになる。
 */
function norm_(s) {
  return String(s || '').normalize('NFKC').replace(/\s+/g, '').toLowerCase();
}

/**
 * 工程1 図面を読み取る。
 *
 * 画面から工程ごとに呼ぶため、独立した関数に分けてある。
 * まとめて1回で呼ぶと、6分の実行時間制限に近づくうえ、
 * 画面側では「動いているのか止まっているのか」が分からない。
 *
 * @param {string} fileId 図面PDFのDriveファイルID
 * @param {number} pageNo 対象のページ番号。既定は1
 * @return {Object} 次の工程に渡す状態
 */
function stepExtract(fileId, pageNo) {
  const cfg = getConfig();
  const blob = DriveApp.getFileById(fileId).getBlob();
  const extracted = askWithPdf(blob, extractPrompt_(pageNo || 1), cfg) || {};
  const texts = extracted.texts || [];
  Logger.log('工程1 抽出 %s件', texts.length);
  return {
    fileId: fileId, pageNo: pageNo || 1, fileName: blob.getName(),
    extracted: extracted, textCount: texts.length,
    drawingTitle: extracted.drawing_title || '',
    drawingNumber: extracted.drawing_number || '',
    scale: extracted.scale || ''
  };
}

/** 工程2 基準に当てはめる。工程1の抽出結果だけを根拠に判定する。 */
function stepJudge(state, target) {
  const cfg = getConfig();
  const items = loadItems(target, cfg);
  if (!items.length) {
    throw new Error('チェック項目が読み込めませんでした。項目表をご確認ください。');
  }
  const judged = askText(judgePrompt_(state.extracted, items), cfg) || {};
  Logger.log('工程2 判定 %s件', (judged.results || []).length);
  state.target = target;
  state.items = items;
  state.results = judged.results || [];
  state.itemCount = items.length;
  return state;
}

/**
 * 工程3 根拠を照合する。ここだけはAIを使わない。
 *
 * AIが根拠として挙げた文字列が、工程1の読み取り結果に実在するか
 * 突き合わせる。無ければ、判定が正しそうに見えても採用しない。
 */
function stepVerify(state) {
  // 照合先には texts だけでなく、図面名・図面番号・縮尺も含める。
  // モデルはこれらを根拠に挙げるが、texts には入れないため、
  // texts だけを見ていると正しい根拠まで棄却してしまう。
  const ex = state.extracted || {};
  const texts = ex.texts || [];
  const hay = norm_([ex.drawing_title, ex.drawing_number, ex.scale]
    .concat(texts.map(function (t) { return t.text; })).join(' '));
  const byNo = {};
  (state.items || []).forEach(function (r) { byNo[String(r.no)] = r; });

  const out = { 確定: [], 要確認: [], 棄却: [] };
  (state.results || []).forEach(function (r) {
    const src = byNo[String(r.no)] || {};
    const rec = {
      no: r.no, item: src.item || '', basis: src.basis || '',
      source: src.source || '', verdict: r.verdict,
      evidence: r.evidence || '', reason: r.reason || ''
    };
    if (r.verdict === '適合') {
      if (!rec.evidence) {
        rec.drop = '根拠が示されていません';
        out.棄却.push(rec);
      } else if (hay.indexOf(norm_(rec.evidence)) < 0) {
        rec.drop = '根拠とされた記載が図面から読み取れていません';
        out.棄却.push(rec);
      } else {
        out.確定.push(rec);
      }
    } else if (r.verdict !== '対象外') {
      out.要確認.push(rec);
    }
  });
  Logger.log('工程3 確定%s / 要確認%s / 棄却%s',
    out.確定.length, out.要確認.length, out.棄却.length);

  return {
    fileName: state.fileName, target: state.target,
    drawingTitle: state.drawingTitle, drawingNumber: state.drawingNumber,
    scale: state.scale, itemCount: state.itemCount,
    textCount: state.textCount, buckets: out
  };
}

/**
 * 図面1枚をチェックする。工程1〜3をまとめて実行する。
 * エディタから runCheck で試すときはこちらを使う。
 *
 * @param {string} fileId 図面PDFのDriveファイルID
 * @param {string} target 図面の種類（例「配置図」）
 * @param {number} pageNo 対象のページ番号。既定は1
 * @return {Object} 判定結果
 */
function checkDrawing(fileId, target, pageNo) {
  return stepVerify(stepJudge(stepExtract(fileId, pageNo), target));
}

/**
 * 結果をスプレッドシートに書き出す。
 * 棄却したものも残す。消すと「問題なし」に見えてしまう。
 */
function writeResult(result) {
  const cfg = getConfig();
  const ss = SpreadsheetApp.openById(cfg.itemsSheetId);
  let sh = ss.getSheetByName(cfg.resultSheetName);
  if (!sh) sh = ss.insertSheet(cfg.resultSheetName);
  sh.clear();

  const COLS = 6;
  const rows = [
    ['実行日時', Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd HH:mm')],
    ['図面', result.fileName, '図面名', result.drawingTitle,
     '図面番号', result.drawingNumber],
    ['対象', result.target, '縮尺', result.scale,
     '読み取り件数', result.textCount],
    [],
    ['区分', 'No', 'チェック項目', '根拠 / 理由', '基準', '出典']
  ];

  ['要確認', '棄却', '確定'].forEach(function (key) {
    result.buckets[key].forEach(function (r) {
      rows.push([
        key, r.no, r.item,
        key === '棄却' ? r.drop + '（AIの根拠: ' + (r.evidence || 'なし') + '）'
                       : (key === '確定' ? r.evidence : r.reason),
        r.basis, r.source
      ]);
    });
  });

  // setValues は全行が同じ列数であることを求める。
  // 空行や短い行が1つでもあるとそこで落ちる。実機でこれに当たった。
  // 原因の行だけ直すのではなく、書く直前に必ず揃える。
  const padded = rows.map(function (row) {
    const out = (row || []).slice(0, COLS);
    while (out.length < COLS) out.push('');
    return out.map(function (v) {
      return (v === null || v === undefined) ? '' : v;
    });
  });

  sh.getRange(1, 1, padded.length, COLS).setValues(padded);
  sh.getRange(5, 1, 1, COLS).setFontWeight('bold').setBackground('#EDF1F5');
  sh.setColumnWidth(3, 320);
  sh.setColumnWidth(4, 360);
  sh.setColumnWidth(5, 300);
  sh.setFrozenRows(5);
  Logger.log('結果を「%s」に書き出しました', cfg.resultSheetName);
  return sh.getParent().getUrl() + '#gid=' + sh.getSheetId();
}

/**
 * クロス品番のリピート属性を調べる。
 *
 * 8/20 の定例で挙がった要件をそのまま実装したもの。
 *   「クロスが10個あったら、10個検索しに行かないといけない」
 *   「型番しか載っていないので、どんな種類のクロスか分からない」
 *   「そこからリピートが必要かどうかを判断する」
 *   「人も後で確認できるようにURLを残しておく」
 *
 * 工程1 抽出   図面 → 品番の一覧（Gemini）
 * 工程2 調査   品番1件ずつ、メーカー公式ページを取得（コード）
 * 工程3 判定   ページの記載からリピートを読む（コード）
 *
 * URLをモデルに答えさせない。Python版の最初の実装ではモデルに
 * URLも答えさせ、10件中6件が google.com/search のURLになった。
 * 「人が後で確認できるようURLを残す」のが目的なのに、検索エンジンに
 * 飛ばすだけでは確認にならない。
 * URLは品番の形からコードが組み立て、実在するかはHTTPで確かめる。
 *
 * リピートの値もモデルに読ませない。ページの決まった場所にある値なので、
 * 正規表現で取れば確実に取れる。読み違いが起きない。
 *
 * 1件ずつ画面から呼ぶ。10件をまとめて回すと6分の制限に当たる。
 */

const UA_ = 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7)';

/**
 * メーカーごとの規則。
 * いずれも実際にアクセスして確かめたもの。
 */
const MAKERS_ = [
  {
    name: 'サンゲツ',
    // RE=リザーブ, FE=ファイン, TH=Sリフォーム系, SP など
    patterns: [/^(RE|FE|TH|SP|XB|EB|BB|WD)\d/, /^[A-Z]{2}\d{4,5}$/],
    detail: 'https://www.sangetsu.co.jp/product/detail/{code}/',
    search: 'https://www.sangetsu.co.jp/product/list/part/{code}',
    legacy: 'https://sangetsu.my.salesforce-sites.com/sscp',
    note: '商品ページは現行カタログのみ。旧品番は404になるため旧品番照会へ誘導する'
  },
  {
    name: 'リリカラ',
    patterns: [/^LL[-\s]?\d/, /^LW[-\s]?\d/, /^LV[-\s]?\d/],
    detail: '',
    // サイト内検索。商品検索の search.php は空クエリでも500を返すため使わない。
    search: 'https://search-lilycolor.dga.jp/?kw={code}&ie=u',
    legacy: '',
    note: 'サイト内検索。リピートの値はこのページに載らないため、件数のみ確認できる'
  }
];

/** 品番の形からメーカーを判定する。分からなければ null。 */
function detectMaker_(code) {
  const c = String(code || '').trim().toUpperCase();
  for (let i = 0; i < MAKERS_.length; i++) {
    const m = MAKERS_[i];
    for (let j = 0; j < m.patterns.length; j++) {
      if (m.patterns[j].test(c)) return m;
    }
  }
  return null;
}

/**
 * URLを取得する。到達確認と本文取得を1回で済ませる。
 * 担当者に渡す前に、そのURLが実際に開けるかを確かめる。
 * メーカー側の不具合でページが落ちることがある。
 */
function fetch_(url) {
  if (!url) return { status: 0, body: '' };
  try {
    const res = UrlFetchApp.fetch(url, {
      headers: { 'User-Agent': UA_ },
      muteHttpExceptions: true,
      followRedirects: true,
      validateHttpsCertificates: true
    });
    return { status: res.getResponseCode(), body: res.getContentText() };
  } catch (e) {
    return { status: 0, body: '' };
  }
}

/**
 * サンゲツの商品ページからリピートを読む。
 *
 * 静的HTMLの数値はミリメートル。表示上のcmはページ側のJSが変換している。
 * そのまま「638cm」と読むと10倍になる。
 * 規格が 920 × 50000（＝92cm × 50m の壁紙規格）と一致することから、
 * mm であることを確認済み。RE55621/55664/55506/55622 の4件で、
 * 別経路で得た値と一致することも確かめた。
 */
function readSangetsu_(html) {
  const v = (html.match(/class="vp_repeat_vert">([^<]*)</) || [])[1];
  const h = (html.match(/class="vp_repeat_hori">([^<]*)</) || [])[1];
  if (v === undefined && h === undefined) {
    // ページの作りが変わった可能性がある。推測で埋めず、人に回す。
    return { repeat: '不明', evidence: 'ページからリピート欄を読み取れませんでした' };
  }
  const cm = function (s) {
    const n = parseFloat(s);
    return isNaN(n) ? null : Math.round(n / 10 * 10) / 10;
  };
  const cv = cm(v), ch = cm(h);
  if (cv === null && ch === null) {
    // 欄はあるが空。無地などリピートを持たない品番がこの形になる。
    return { repeat: 'リピートなし', evidence: 'リピート欄が空欄' };
  }
  return {
    repeat: 'リピートあり',
    evidence: 'タテ' + (cv === null ? '―' : cv) + 'cm ヨコ' +
              (ch === null ? '―' : ch) + 'cm'
  };
}

/**
 * リリカラの検索ページから該当件数を読む。
 * このページにリピートの値は載らないため、リピートは「不明」のままにする。
 * 分からないものを埋めない。
 */
function readLilycolor_(html) {
  // 件数の前後にタグが挟まる。素のHTMLに正規表現をかけると当たらない。
  // タグを落として本文にしてから拾う。
  const text = String(html)
    .replace(/<script[\s\S]*?<\/script>|<style[\s\S]*?<\/style>/g, ' ')
    .replace(/<[^>]+>/g, ' ')
    .replace(/\s+/g, ' ');
  const m = text.match(/検索結果は\s*([\d,]+)\s*件/);
  const n = m ? parseInt(m[1].replace(/,/g, ''), 10) : null;
  if (n === null) {
    return { repeat: '不明', evidence: '検索結果の件数を読み取れませんでした' };
  }
  if (n === 0) {
    return { repeat: '不明', evidence: '現行カタログに該当なし' };
  }
  return { repeat: '不明',
           evidence: '検索結果 ' + n + '件。リピートはページに未掲載のため要確認' };
}

/**
 * 品番1件を調べる。画面から1件ずつ呼ぶ。
 *
 * 優先順位は 商品ページ > 品番検索 > 旧品番照会。
 * 商品ページが200で返ればそれを採る。404なら現行カタログに無いということなので、
 * 品番検索と旧品番照会に回す。
 */
function repeatOne(item) {
  const code = String(item.code || '').trim();
  const out = {
    code: code, alt: item.alt || '', part: item.part || '',
    maker: '', url: '', urlKind: 'なし', legacyUrl: '',
    repeat: '不明', evidence: ''
  };

  // 図面には「OAS-721（SP9734）」のように旧品番と現行品番が併記される。
  // 旧品番の形はメーカー規則に当たらないため、併記された方でも判定する。
  // これを入れないと、併記のある品番が丸ごと「判定できません」になる。
  let lookup = code;
  let maker = detectMaker_(code);
  if (!maker && out.alt) {
    maker = detectMaker_(out.alt);
    if (maker) lookup = String(out.alt).trim();
  }
  if (!maker) {
    out.evidence = '品番の形からメーカーを判定できませんでした';
    return out;
  }
  out.maker = maker.name;
  out.legacyUrl = maker.legacy;
  out.lookup = lookup;

  const enc = encodeURIComponent(lookup);
  const detail = maker.detail ? maker.detail.replace('{code}', enc) : '';
  const search = maker.search ? maker.search.replace('{code}', enc) : '';

  if (detail) {
    const r = fetch_(detail);
    if (r.status === 200) {
      out.url = detail;
      out.urlKind = '商品ページ';
      const read = readSangetsu_(r.body);
      out.repeat = read.repeat;
      out.evidence = read.evidence;
      return out;
    }
  }

  if (search) {
    const r = fetch_(search);
    if (r.status >= 200 && r.status < 400) {
      out.url = search;
      out.urlKind = '品番検索';
      const read = maker.name === 'リリカラ'
        ? readLilycolor_(r.body)
        : { repeat: '不明', evidence: '現行カタログに該当なし' };
      out.repeat = read.repeat;
      out.evidence = read.evidence;
      return out;
    }
    out.evidence = '品番検索のページが応答しません（HTTP ' + (r.status || '接続不可') + '）';
  }
  return out;
}

/**
 * 図面フォルダにあるPDFの一覧を作る。
 *
 * AppSheet の「図面」シートの中身は、ここが作る。
 * 画面（Ui.gs）を外した構成でも、この関数だけは必要になるため独立させた。

/**
 * フォルダにある図面PDFの一覧。画面の選択肢に使う。
 *
 * 見つからないときに空で返さない。空の選択肢だけが出ても、
 * 設定が抜けているのか、フォルダが空なのか、権限が無いのかが分からない。
 * 理由を投げて、画面に出す。
 */
function listDrawings() {
  const cfg = getConfig();
  if (!cfg.drawingFolderId) {
    throw new Error(
      'DRAWING_FOLDER_ID が未設定です。setupProperties を実行してください。' +
      '（コードを貼り直したあとは、もう一度実行が必要です）');
  }

  let folder;
  try {
    folder = DriveApp.getFolderById(cfg.drawingFolderId);
  } catch (e) {
    throw new Error('図面フォルダを開けませんでした（ID: ' + cfg.drawingFolderId +
                    '）。IDが正しいか、閲覧権限があるかをご確認ください。');
  }

  // 直下だけでなく、1階層下のサブフォルダも見る。
  // 実運用のドライブは案件ごとにフォルダが切られていることが多く、
  // 直下しか見ないと「フォルダを指定したのに空」になる。
  // 深追いはしない。階層が深いドライブだと6分の制限に当たる。
  const out = [];
  collectPdfs_(folder, '', out);
  const sub = folder.getFolders();
  while (sub.hasNext() && out.length < MAX_DRAWINGS) {
    const f = sub.next();
    collectPdfs_(f, f.getName(), out);
  }

  if (!out.length) {
    throw new Error('図面フォルダにPDFが見つかりませんでした（' + folder.getName() +
                    '）。直下と、その1つ下のフォルダまでを見ています。' +
                    'それより深い場所にある場合は、フォルダIDをそこに変えてください。');
  }
  out.sort(function (a, b) { return a.name.localeCompare(b.name, 'ja'); });
  return out;
}

const MAX_DRAWINGS = 200;

/**
 * フォルダ直下のPDFを集める。
 *
 * getFilesByType(PDF) だけに頼らない。取り込み方によっては
 * mimeType が application/pdf にならないことがあり、
 * その場合に1件も出ずに理由も分からなくなる。拡張子でも拾う。
 */
function collectPdfs_(folder, prefix, out) {
  const it = folder.getFiles();
  while (it.hasNext() && out.length < MAX_DRAWINGS) {
    const f = it.next();
    const name = f.getName();
    if (f.getMimeType() !== MimeType.PDF && !/\.pdf$/i.test(name)) continue;
    out.push({
      id: f.getId(),
      // どのフォルダのものか分かるようにする。
      // 案件が違うだけで同名のファイルが並ぶため、名前だけでは選べない。
      name: prefix ? prefix + ' ／ ' + name : name,
      mb: Math.round(f.getSize() / 1048576 * 10) / 10
    });
  }
}

/**
 * AppSheet から使うためのデータ層。
 *
 * AppSheet はスプレッドシートを直接読み書きする。
 * これまでの「チェック結果」シートは、実行のたびに clear() して
 * 見出し4行のあとに結果を並べる帳票の形だった。
 * この形は AppSheet では扱えない。理由は3つある。
 *   ・行を一意に指すキー列が無い
 *   ・毎回消えるので、担当者が付けた確認済みやコメントが残らない
 *   ・見出しブロックがあるため、1行目＝列名にならない

 *

/**
 * AppSheet が読むシートを作る。1回だけ実行する。
 * すでにある場合は中身を触らない。列だけ足りなければ足す。
 */
function setupAppSheetSheets() {
  const cfg = getConfig();
  const ss = SpreadsheetApp.openById(cfg.itemsSheetId);
  const made = [];

  Object.keys(AS_SHEETS).forEach(function (key) {
    const name = AS_SHEETS[key];
    const cols = AS_COLS[key];
    let sh = ss.getSheetByName(name);
    if (!sh) {
      sh = ss.insertSheet(name);
      sh.getRange(1, 1, 1, cols.length).setValues([cols]);
      made.push(name);
    } else {
      // 既存シートの見出しが短いときだけ、足りない列を右に足す。
      // 並べ替えや書き換えはしない。既存の行がずれる。
      const width = Math.max(sh.getLastColumn(), 1);
      const head = sh.getRange(1, 1, 1, width).getValues()[0]
        .map(function (v) { return String(v).trim(); });
      const add = cols.filter(function (c) { return head.indexOf(c) < 0; });
      if (add.length) {
        sh.getRange(1, width + 1, 1, add.length).setValues([add]);
      }
    }
    sh.getRange(1, 1, 1, sh.getLastColumn())
      .setFontWeight('bold').setBackground('#EDF1F5');
    sh.setFrozenRows(1);
  });

  // 図面の取り込みで失敗しても、シートは作れたところまで残す。
  // ここで投げると「シートが1つもできなかった」ように見えて、
  // 原因がフォルダ設定であることが分からなくなる。
  let note = '';
  try {
    note = '図面 ' + refreshDrawings() + '件';
  } catch (e) {
    note = '図面の取り込みは失敗しました（' + e.message + '）。' +
           'フォルダを設定してから refreshDrawings() を実行してください';
  }

  asLog_('準備', '', 'シートを用意しました。新規作成: ' +
         (made.length ? made.join(' / ') : 'なし') + '。' + note);
  return ss.getUrl();
}


function asSheet_(key) {
  const cfg = getConfig();
  const ss = SpreadsheetApp.openById(cfg.itemsSheetId);
  const sh = ss.getSheetByName(AS_SHEETS[key]);
  if (!sh) {
    throw new Error('「' + AS_SHEETS[key] + '」シートがありません。' +
                    'setupAppSheetSheets() を実行してください。');
  }
  return sh;
}


/**
 * 見出し行を読んで、列名 → 列番号（1始まり）を返す。
 *
 * 列の位置を数字で決め打ちしない。AppSheet 側で列を足したり
 * 並べ替えたりすることがあり、そのたびに書き込み先がずれる。
 */
function asHeader_(sh) {
  const width = Math.max(sh.getLastColumn(), 1);
  const head = sh.getRange(1, 1, 1, width).getValues()[0];
  const map = {};
  head.forEach(function (v, i) {
    const name = String(v).trim();
    if (name && map[name] === undefined) map[name] = i + 1;
  });
  return map;
}


/**
 * オブジェクトの配列を追記する。
 *
 * setValues は全行が同じ列数であることを求める。
 * 短い行が1つでもあるとそこで落ちる。書く直前に必ず揃える。
 */
function asAppend_(sh, records) {
  if (!records.length) return 0;
  const map = asHeader_(sh);
  const width = Math.max(sh.getLastColumn(), 1);
  const rows = records.map(function (rec) {
    const row = new Array(width).fill('');
    Object.keys(rec).forEach(function (k) {
      const at = map[k];
      const v = rec[k];
      if (at) row[at - 1] = (v === null || v === undefined) ? '' : v;
    });
    return row;
  });
  sh.getRange(sh.getLastRow() + 1, 1, rows.length, width).setValues(rows);
  return rows.length;
}


function asNow_() {
  return Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd HH:mm:ss');
}


/**
 * 実行ログを「実行ログ」シートに残す。
 *
 * Logger.log は Apps Script の実行ログにしか出ない。
 * 担当者は AppSheet しか見ないため、そこで止まると何が起きたか分からない。
 * とくに依頼の行を見つける前に落ちた場合、どこにも記録が残らない。
 *
 * ログを書けなかったことで本体を止めない。
 * ログのために処理が落ちるのは、本末転倒になる。
 *
 * 毎分のトリガーで「何もなかった」まで書くと、1日1440行になる。
 * 動きがあったときだけ呼ぶ。
 */
const AS_LOG_MAX = 2000;   // これを超えたら古い行から消す

function asLog_(kind, requestId, message) {
  Logger.log('[%s] %s %s', kind, requestId || '-', message);
  try {
    const sh = asSheet_('log');
    asAppend_(sh, [{
      '日時': asNow_(), '区分': kind,
      '依頼ID': requestId || '',
      '内容': String(message == null ? '' : message).slice(0, 900)
    }]);

    // 際限なく伸ばさない。古い行から落とす。
    const last = sh.getLastRow();
    if (last > AS_LOG_MAX + 1) sh.deleteRows(2, last - AS_LOG_MAX - 1);
  } catch (e) {
    // ここで投げない。実行ログが書けないだけで依頼の処理は続ける。
    Logger.log('実行ログに書けませんでした: %s', e.message);
  }
}

/**
 * 図面フォルダの中身を「図面」シートに反映する。
 *
 * 行を消さない。消すと、その図面を指している過去の依頼が参照先を失う。
 * 無くなったものは「有効」を空にして残す。
 */
function refreshDrawings() {
  const sh = asSheet_('drawings');
  const found = listDrawings();   // Drawings.gs。見つからなければ理由を投げる
  const map = asHeader_(sh);
  const last = sh.getLastRow();

  const rowOf = {};
  if (last >= 2) {
    const ids = sh.getRange(2, map['図面ID'], last - 1, 1).getValues();
    ids.forEach(function (r, i) {
      const id = String(r[0] || '').trim();
      if (id) rowOf[id] = i + 2;
    });
  }

  const seen = {};
  const add = [];
  const now = asNow_();
  found.forEach(function (d) {
    seen[d.id] = true;
    if (rowOf[d.id]) {
      const at = rowOf[d.id];
      sh.getRange(at, map['ファイル名']).setValue(d.name);
      sh.getRange(at, map['サイズMB']).setValue(d.mb);
      sh.getRange(at, map['更新日時']).setValue(now);
      sh.getRange(at, map['有効']).setValue('○');
    } else {
      add.push({ '図面ID': d.id, 'ファイル名': d.name, 'サイズMB': d.mb,
                 '更新日時': now, '有効': '○' });
    }
  });

  // フォルダから消えたものに印を付ける。行そのものは残す。
  Object.keys(rowOf).forEach(function (id) {
    if (!seen[id]) sh.getRange(rowOf[id], map['有効']).setValue('');
  });

  asAppend_(sh, add);
  asLog_('図面一覧', '', found.length + '件（新規 ' + add.length + '件）');
  return found.length;
}

/**
 * 「受付」の依頼を順に処理する。時間主導トリガーから呼ぶ。
 *
 * 1回の起動で全部を処理しない。時間切れになると状態が「処理中」で残り、
 * 次の起動が同じ依頼をもう一度動かす。手前で止めて次の起動に回す。
 */
function runPending() {
  const started = Date.now();

  // 依頼の行にたどり着く前に落ちることがある。
  // シートが無い、プロパティが未設定、スプレッドシートを開けない——
  // そのとき担当者は AppSheet しか見ないため、理由がどこにも残らない。
  // ここで捕まえて実行ログに書く。
  let sh, map;
  try {
    sh = asSheet_('requests');
    map = asHeader_(sh);
  } catch (e) {
    asLog_('エラー', '', '依頼シートを読めませんでした: ' + e.message);
    throw e;
  }

  const last = sh.getLastRow();
  if (last < 2) {
    Logger.log('依頼はありません');   // 毎分呼ばれる。何も無い回はシートに書かない
    return 0;
  }

  const width = sh.getLastColumn();
  const values = sh.getRange(2, 1, last - 1, width).getValues();
  let done = 0;

  for (let i = 0; i < values.length; i++) {
    const status = String(values[i][map['状態'] - 1] || '').trim();
    if (status !== AS_STATUS.queued) continue;

    // 次の1件を始める前に、残り時間を見る。
    // 途中で打ち切られるより、始めないほうがよい。
    if (Date.now() - started > AS_DEADLINE_MS * 0.5) {
      asLog_('中断', '', '時間が残り少ないため、ここで区切りました（' + done +
             '件処理）。残りは次の起動で処理します');
      break;
    }
    processRequestAt_(sh, map, i + 2, values[i], started);
    done++;
  }

  Logger.log('依頼を %s件処理しました', done);
  return done;
}


/**
 * 依頼IDを指定して1件だけ処理する。
 * AppSheet の Apps Script タスクから呼ぶ場合はこちらを使う。
 *
 * ただし AppSheet 側は2分（アプリイベント）で打ち切られる。
 * 図面によっては収まらないため、既定はトリガー方式（runPending）を勧める。
 */
function appsheetRun(requestId) {
  const started = Date.now();
  const sh = asSheet_('requests');
  const map = asHeader_(sh);
  const last = sh.getLastRow();
  if (last < 2) throw new Error('依頼が1件もありません。');

  const width = sh.getLastColumn();
  const values = sh.getRange(2, 1, last - 1, width).getValues();
  const want = String(requestId || '').trim();
  for (let i = 0; i < values.length; i++) {
    if (String(values[i][map['依頼ID'] - 1] || '').trim() === want) {
      return processRequestAt_(sh, map, i + 2, values[i], started);
    }
  }
  throw new Error('依頼ID「' + want + '」が見つかりませんでした。');
}


/**
 * 依頼1行を処理する。
 *
 * 何が起きても状態を書き戻す。失敗したまま「処理中」で残さない。
 * 残ると、担当者からは動いているのか壊れているのか見分けが付かない。
 */
function processRequestAt_(sh, map, rowNo, row, started) {
  const get = function (name) {
    const at = map[name];
    return at ? String(row[at - 1] || '').trim() : '';
  };
  const set = function (name, v) {
    const at = map[name];
    if (at) sh.getRange(rowNo, at).setValue(v);
  };

  const requestId = get('依頼ID') || ('R' + Date.now());
  if (!get('依頼ID')) set('依頼ID', requestId);
  set('状態', AS_STATUS.running);
  set('メッセージ', '');
  SpreadsheetApp.flush();   // 途中で落ちても「処理中」が見えるようにする

  try {
    const fileId = get('図面ID');
    if (!fileId) throw new Error('図面が選ばれていません。');
    const kind = get('種別') || AS_KIND.check;
    const pageNo = Number(get('ページ')) || 1;

    const out = (kind === AS_KIND.repeat)
      ? runRepeatRequest_(requestId, fileId, pageNo, started)
      : runCheckRequest_(requestId, fileId, get('対象'), pageNo);

    set('ファイル名', out.fileName);
    set('件数', out.count);
    set('状態', AS_STATUS.done);
    set('メッセージ', out.message);
    set('完了日時', asNow_());
    asLog_('完了', requestId, out.fileName + ' … ' + out.message);
    return out.message;

  } catch (e) {
    const why = String(e && e.message ? e.message : e);
    set('状態', AS_STATUS.error);
    set('メッセージ', why.slice(0, 900));
    set('完了日時', asNow_());
    asLog_('エラー', requestId, why);
    return 'エラー: ' + e;
  }
}


/** 図面チェック。工程1〜3を通し、判定シートに1項目1行で追記する。 */
function runCheckRequest_(requestId, fileId, target, pageNo) {
  const result = stepVerify(stepJudge(stepExtract(fileId, pageNo), target));

  const sh = asSheet_('judges');
  const records = [];
  let n = 0;
  ['要確認', '棄却', '確定'].forEach(function (key) {
    (result.buckets[key] || []).forEach(function (r) {
      n++;
      records.push({
        '判定ID': requestId + '-' + n,
        '依頼ID': requestId,
        '区分': key,
        'No': r.no,
        'チェック項目': r.item,
        '判定': r.verdict,
        // 棄却したものは、AIが挙げた根拠と、なぜ採らなかったかを両方残す。
        // 消すと「問題なし」に見えてしまう。
        '根拠': key === '棄却' ? (r.evidence || '') : (r.evidence || ''),
        '理由': key === '棄却' ? r.drop : (r.reason || ''),
        '基準': r.basis,
        '出典': r.source,
        '確認済み': '',
        '担当コメント': ''
      });
    });
  });
  asAppend_(sh, records);

  // 帳票としてのチェック結果シートも従来どおり残す。用途が違う。
  writeResult(result);

  const b = result.buckets;
  return {
    fileName: result.fileName,
    count: records.length,
    message: '確定' + b.確定.length + ' / 要確認' + b.要確認.length +
             ' / 棄却' + b.棄却.length + '（読み取り' + result.textCount + '件）'
  };
}


/**
 * 品番リピート。抽出は1回、そのあと1品番ごとにメーカーページを見る。
 *
 * 件数が多いと6分に届く。届く手前で止めて、そこまでを書き残す。
 * 残りは「未確認」として行に残すので、もう一度依頼すれば続きから追える。
 */
function runRepeatRequest_(requestId, fileId, pageNo, started) {
  const found = extractCodes(fileId, pageNo);
  const sh = asSheet_('codes');
  const records = [];
  let stopped = 0;

  found.codes.forEach(function (c, i) {
    if (Date.now() - started > AS_DEADLINE_MS) {
      stopped++;
      records.push({
        '品番ID': requestId + '-' + (i + 1),
        '依頼ID': requestId,
        '品番': c.code, '併記品番': c.alt || '', '部位': c.part || '',
        'メーカー': '', 'リピート': '未確認',
        '根拠': '時間内に調べきれませんでした。もう一度ご依頼ください',
        'URL': '', 'URL種別': 'なし', '旧品番照会': '',
        '確認済み': '', '担当コメント': ''
      });
      return;
    }
    const r = repeatOne(c);
    records.push({
      '品番ID': requestId + '-' + (i + 1),
      '依頼ID': requestId,
      '品番': r.code, '併記品番': r.alt || '', '部位': r.part || '',
      'メーカー': r.maker, 'リピート': r.repeat, '根拠': r.evidence,
      'URL': r.url, 'URL種別': r.urlKind, '旧品番照会': r.legacyUrl,
      '確認済み': '', '担当コメント': ''
    });
  });

  asAppend_(sh, records);

  const ok = records.length - stopped;
  return {
    fileName: found.fileName,
    count: records.length,
    message: '品番' + records.length + '件を抽出、' + ok + '件を照会' +
             (stopped ? '（' + stopped + '件は時間切れで未確認）' : '')
  };
}

いちばん危なかったこと

ノーコード側は、図面本体を1文字も読んでいないのに 「読み取れなかった箇所: なし」と返しました。

読み落としを、モデル自身が認識していません。 同じ流れで判定まで進めると、本体を見ていないのに「基準を満たしている」という 結論が出ます。コード側には根拠が読み取り結果に実在するか照合する工程を 入れてあり、そこだけはAIを使いません。運用1回目で、実在しない根拠を挙げた判定が 1件棄却されました。

ノーコードで届く範囲

公平に言えば、図面枠は読めています。 チェック項目のうち、図面枠だけで判定できるものは6件あります。

No図面枠だけで判定できる項目
1縮尺が規定の値になっているか
2図面番号が規定の記号になっているか
3図面枠に必要事項が記入されているか
4図面番号が2ケタ表示になっているか
5縮尺の記入があるか
6設計担当者名がフルネームで記載されているか
それでも、この6件のためにノーコードを併用しません。 同じ6件はコード側でも判定できており、機能が増えません。 同じ図面を2つの仕組みが読むと、結果が食い違ったときに どちらが正しいか決められなくなります。

途中で起きた失敗

同じところで詰まるため、残しています

URLをモデルに答えさせていた

10件中6件が google.com/search?q=… という検索エンジンのURLになった。人が後で確認するためのURLなのに、Google検索に飛ばすだけでは確認にならない。

直し方 品番の形からメーカーを判定し、コードがURLを組み立てる形に変えた。検索エンジンのURLはゼロになった。

検証が甘く、10件すべてが確定に見えた

URLと根拠が「空でないこと」しか見ていなかったため、検索エンジンのURLでも確定として通っていた。

直し方 メーカーの商品ページに到達したものだけを確定とした。結果は 確定4件 / 要確認6件。こちらが実態。

権限の指定が足りず、AIを呼べなかった

コードを貼り付けただけでは cloud-platform の権限が付かず、HTTP 403 insufficient authentication scopes で止まった。Apps Script はコードから使う権限を推測するが、外部リクエストの先までは分からない。

直し方 設定ファイル（appsscript.json）に権限を明示した。手順にもその工程を入れ、飛ばせないようにした。

結果の書き出しで落ちた

表に書き込む際、空行だけ列数が0で、「データの列数と範囲の列数が一致しません」で止まった。判定そのものは終わっていたのに、結果が残らなかった。

直し方 書き込む直前に全行の列数を揃える処理を入れた。原因の行を直すのではなく、以後どんな行が来ても揃うようにした。

ループが指定回数まで空回りしていた

待ち行列が尽きたときに escalate でループを抜ける実装にしたが、コールバックからイベントに伝播せず、上限まで回っていた。

直し方 抽出を先に走らせ、件数が確定してから max_iterations を決める2段構えにした。
